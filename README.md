# Dynamic Shopping Cart

## Project Description

This project is a simple shopping cart application created using HTML, 
CSS, and JavaScript. It allows users to add and remove products 
dynamically and updates the total price automatically.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- DOM Manipulation

## Features

- Add products with a name and price.
- Display products in the shopping cart.
- Remove individual products from the cart.
- Automatically update the total price.
- Validate product name and price.
- Clear input fields after adding a product.

## Project Structure

- `index.html` - Contains the structure of the application.
- `style.css` - Contains the styling of the application.
- `script.js` - Contains the JavaScript functionality.
- `reflections.md` - Contains my answers to the reflection questions.
- `README.md` - Contains information about the project.

## How to Run

1. Clone or download the repository.
2. Open the project folder in VS Code.
3. Open `index.html` in a browser or use Live Server.
4. Enter a product name and price and click Add Product.
5. Click Remove to delete a product from the cart.
